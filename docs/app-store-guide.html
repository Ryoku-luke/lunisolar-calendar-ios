0 开始前的准备

磨刀不误砍柴工，先把硬件和账号准备好

🧰 你需要的东西

物品要求用途
Mac 电脑M1/M2/M3/M4 或 Intel 均可，macOS 14+运行 Xcode
Xcode16.0 或更新版本（App Store 免费下载）编译 App
iPhoneiOS 17 或更新真机测试
数据线iPhone 原装 Lightning / USB-C连接 Mac 和 iPhone
Apple ID普通 Apple ID 可真机调试；上架需 付费开发者账号（$99/年）签名 & 上架

💰 关于付费开发者账号

⚠️
真机调试：免费 用普通 Apple ID 就能在自己的手机上跑 App，有效期 7 天。
上架 App Store：必须付费 需要加入 Apple Developer Program，年费 $99（约 ¥688）。可在 developer.apple.com/programs 注册。

⬇️ 安装 Xcode

打开 Mac 上的 App Store，搜索 Xcode，点击「获取」下载（约 12GB，耐心等待）。
安装完成后打开 Xcode，它会提示安装额外组件（Command Line Tools），点 Install 即可。
打开 Xcode 菜单 Xcode → Settings → Accounts，点左下角 + 登录你的 Apple ID。

1 下载源代码

把「清和日历」的代码拿到你的 Mac 上

方式一：从 GitHub 下载（推荐）

在浏览器打开项目的 GitHub 仓库地址。
点击绿色的 Code 按钮 → 选 Download ZIP。
下载完成后，双击 ZIP 解压，把文件夹拖到「下载」或「文稿」目录。

方式二：用 git 命令（如果你装过）

# 打开「终端」App，粘贴以下命令回车
git clone https://github.com/你的用户名/qinghe-calendar.git
# 代码会下载到当前目录的 qinghe-calendar 文件夹
📂
下载后你会看到这些核心文件 Package.swift（项目入口）、Sources/（代码）、Assets/（图标和资源）、README.md（说明）。

2 用 Xcode 打开项目

本项目是 Swift Package，没有 .xcodeproj 文件，直接打开 Package.swift 即可

打开 Xcode，菜单 File → Open…（快捷键 ⌘O）。
找到你下载的文件夹，选择里面的 Package.swift 文件，点「打开」。
Xcode 会自动解析项目，左上角进度条走完（第一次可能需要 1-2 分钟下载依赖，本项目无第三方依赖，很快）。
⚠️
注意：SPM 项目没有可直接运行的 App 直接按 Run 会报错，因为这是一个「库」工程。下一步我们需要创建一个「宿主 App」来承载它。这是本教程最关键的一步，请仔细操作。

3 创建宿主 App & 配置签名

给代码套一个「运行壳」，并让你的 Apple ID 给 App 签名

3.1 创建一个空的 iOS App Target

菜单 File → New → Target…。
左侧选 iOS，右侧选 App，点 Next。
填写：
  • Product Name：填 清和日历（或英文名 QingheCalendar）
  • Interface：选 SwiftUI
  • Language：选 Swift
  • 下方 Core Data / Tests / UI Tests 全部不要勾
点 Finish。
Xcode 会生成一些模板文件（ContentView.swift 等），全部删掉（选中按 Delete，选「Move to Trash」）。

3.2 把代码库接入宿主 App

点左侧导航栏最顶部的蓝色项目图标 → 选中你刚创建的 target（清和日历）→ 顶部切到 General 标签。
找到 Frameworks, Libraries, and Embedded Content 区域，点 +。
在弹出的列表里找到 Package Products 分组，勾选 LunisolarCalendarApp，点 Add。
在新出现的那行右侧，把 Embed 列设为 Embed & Sign。

3.3 替换入口文件

在你的宿主 App 文件夹里新建一个 Swift 文件（File → New → File… → Swift File），命名为 HostApp.swift，内容如下：

import SwiftUI
import LunisolarCalendarApp

@main
struct HostApp: App {
    var body: some Scene {
        WindowGroup {
            AdaptiveRootView()
                .environment(EventStore.shared)
        }
    }
}

3.4 配置签名

选中 target → 顶部切到 Signing & Capabilities 标签。
Team 下拉选你的 Apple ID（没登录的回 §0 登录）。
Bundle Identifier 改成你自己的唯一标识，例如 com.你的名字.qinghe。
💡
什么是 Bundle ID？相当于 App 的「身份证号」，全球唯一。随便取一个，只要不和别人重复即可。
勾选 Automatically manage signing（自动管理签名），Xcode 会帮你处理证书。

4 在模拟器上跑起来

先在电脑上的虚拟 iPhone 里看看效果

Xcode 顶部工具栏，Scheme 选你刚创建的 清和日历 target（不是 LunisolarCalendarApp library）。
设备选任意一个模拟器，比如 iPhone 16。
点左上角的 ▶️ 按钮（或按 ⌘R）。
等待编译（约 30 秒~1 分钟），模拟器自动打开，桌面上出现「清和日历」图标。
点开 App，浏览日历、查看黄历、添加日程，确认功能正常。
✅
成功标志 模拟器里能看到日历界面，能切换月份、查看当日宜忌、添加事件。

5 连接真机测试

把 App 装到你自己的 iPhone 上

用数据线把 iPhone 连到 Mac。iPhone 上会弹出「信任此电脑？」，点信任并输入密码。
Xcode 顶部设备下拉框选择你的 iPhone（第一次连接可能提示「Preparing iPhone for development」，等待 1-2 分钟）。
在 iPhone 上打开 设置 → 通用 → VPN与设备管理，找到你的 Apple ID 对应的开发者证书，点信任。
回到 Xcode 按 ⌘R，App 自动安装到手机并打开。
在手机上完整测试：日历、黄历、提醒通知、倒数日、节日主题色、春节图标切换。
🔔
通知权限 第一次进入「设置」页会弹通知权限请求，选「允许」才能收到提醒。
📅
春节图标怎么测？ 正常情况下春节图标只在正月初一前后自动切换。想立即看效果，可以把手机日期临时改成正月初一（设置 → 通用 → 日期与时间），重启 App 即可看到春节限定图标。

6 打包（Archive）

把 App 打包成可上传的安装包

⚠️
上架前必须确认 你已经有付费 Apple Developer 账号，并且 Bundle ID 已在 developer.apple.com/account 注册。
在 Xcode 顶部设备下拉框选 Any iOS Device (arm64)（不要选模拟器或具体手机）。
检查版本号：选中 target → General → 找到：
  • Version（如 1.0.0）：用户在 App Store 看到的版本号
  • Build（如 1）：每次上传必须比上一次大 1
菜单 Product → Archive（或 ⌃⌘⇧B）。
等待编译完成（2-5 分钟），弹出 Organizer 窗口，里面列出你刚打包的 Archive。

7 上传到 App Store Connect

把安装包传到苹果的服务器

在 Organizer 窗口选中你刚打的包，点右侧 Distribute App。
选 App Store Connect → 点 Next。
选 Upload（不是 Export）→ 点 Next。
保持默认勾选（Upload your app's symbols, Manage Version and Build Number 等）→ Next。
确认签名信息 → Upload。等待上传完成（看网速，通常 1-5 分钟）。
✅
上传成功 看到绿色对勾「Upload successful」。此时 App 已进入苹果服务器，但还需要在 App Store Connect 填写信息才能提交审核。

8 填写 App Store 信息

在网页后台填写 App 的名称、描述、截图等

打开 appstoreconnect.apple.com，用你的开发者账号登录。
点 我的 App → 左上角 + → 新建 App。
填写：
  • 平台：iOS
  • 名称：清和日历
  • 主要语言：简体中文
  • 套装 ID（Bundle ID）：选你在 Xcode 里填的那个
  • SKU：随便填一个唯一字符串（如 qinghe2026）
点「创建」。
进入 App 页面，按左侧菜单依次填写：
  • App 信息：类别选「生活」或「效率」
  • 价格与销售范围：选「免费」
  • App 隐私：声明数据收集情况（本 App 不上传用户数据，可声明不收集）
iOS App 版本 页面填写：
  • 上传 App 截图（需要 6.5 寸和 6.7 寸 iPhone 截图，可用模拟器截图）
  • 描述：介绍 App 功能（农历、黄历、节日、倒数日、日程等）
  • 关键词：日历,农历,黄历,节日,倒数日,日程
  • 支持 URL：你的网站或 GitHub 地址
  • 版本号：与 Xcode 里的 Version 一致
在「构建版本」处选择你刚上传的包（上传后需等几分钟才会出现，期间状态显示「正在处理」）。

9 提交审核 & 发布

最后一步：交给苹果审核

所有信息填完后，页面右上角点 添加以供审核。
审核信息页：如果 App 需要登录或特殊测试，在「审核备注」里说明。本 App 无需登录，可留空。
点 提交以供审核。状态变为「等待审核」。
等待审核（通常 24-72 小时，节假日可能更久）。期间会收到邮件通知。
审核通过后，状态变为「准备分发」，点「发布」即可上线 App Store！
🔄
如果被拒了怎么办？ 苹果会在「解决方案中心」写明拒审原因，按要求修改后重新打包上传即可。常见原因：截图不清晰、描述夸大功能、隐私声明不完整。
🎉
恭喜上架！ 全球用户都能在 App Store 搜索「清和日历」下载你的 App 了。

? 常见问题

遇到问题先看这里

Xcode 打开 Package.swift 后没有可运行的 App？ ▼
这是正常的。本项目是 Swift Package（库），没有可执行入口。按「步骤 3」创建一个宿主 App Target 并接入 LunisolarCalendarApp 即可。
真机运行报 "The app identifier cannot be registered"？ ▼
Bundle ID 冲突或没选 Team。在 Signing & Capabilities 里选你的 Team，并把 Bundle Identifier 改成一个全球唯一的值（比如加你的名字）。
模拟器可以跑，真机不行？ ▼
检查：1) iPhone 是否信任了这台 Mac；2) 设置 → 通用 → VPN与设备管理 里是否信任了你的开发者证书；3) Team 是否选对。
免费 Apple ID 装的 App 7 天后闪退？ ▼
这是正常的。免费账号签名的 App 有效期只有 7 天，过期后重新用 Xcode 装一次即可。上架 App Store 需要付费开发者账号，就没有这个限制。
上传后 App Store Connect 一直显示「正在处理」？ ▼
正常，苹果服务器处理安装包需要时间，通常 5-30 分钟。期间可以刷新页面，处理完会自动出现在「构建版本」列表里。
截图尺寸不符合要求？ ▼
需要 6.5 寸（如 iPhone 11 Pro Max / 14 Plus 模拟器）和 6.7 寸（iPhone 14 Pro Max / 15 Pro Max 模拟器）的截图。在模拟器里按 ⌘S 截屏。
Widget 小组件怎么装到手机桌面？ ▼
真机上长按桌面空白处 → 点左上角 + → 搜索「清和」→ 选择喜欢的小组件样式添加。
iCloud 同步不工作？ ▼
需要：1) App ID 绑定了 CloudKit；2) 手机设置里 iCloud Drive 已开启；3) 首次登录 Apple ID 后重启 App。
