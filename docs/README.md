## 五、这次会话最值钱的几条教训（细节见清单/复盘）

- **先取便宜信号，不要连续盲试**：五次盲试 ≈30 分钟还推错了结论；一次诊断 89 秒就推翻了它。
- **诊断用 `throw XCTSkip(内容)` 回传**（失败会触发 Xcode 诊断收集，撞过两次 600 s 超时）。
- **改完必须读回来看**：`edit` 工具比脚本结构推断可靠得多（脚本配对括号/缩进连栽四次）。
- **守卫要能证伪**：我写的横滑守卫第一版比较"整页文案"，摘掉手势仍通过 ✗ —— 是假守卫。
- **警告即失败**：`Tools/typecheck_uitests.sh` 已收紧；它上线后当场抓到我自己一次错误。
- **两个独立问题不要互相顶替**：长按回落的"文字重采样"（系统快照固有）
  与"按下时框缩小/圆角变"（我们自己的 1.05 缩放）是两件事 —— 我一度用一个去解释另一个 ✗。
